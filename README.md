# SpendWise — Smart Expense Tracker

SpendWise is a responsive personal finance web application that helps users track their income, expenses, savings, and monthly budget in one place. It provides a clean dashboard, transaction management, spending insights, and useful tools to make everyday money management easier.

## ✨ Features

- **Dashboard Overview** — View total balance, income, expenses, and savings rate.
- **Transaction Management** — Add, edit, and delete income or expense records.
- **Categories** — Organize transactions by categories.
- **Search & Filters** — Find transactions using search, transaction type, and date filters.
- **Monthly Budget** — Set a monthly budget and monitor spending.
- **Spending Insights** — Visualize financial activity with a chart and category breakdown.
- **CSV Export** — Export transaction records for personal reporting.
- **Multiple Languages** — Switch between English, Bangla, and Banglish.
- **Light & Dark Themes** — Choose a comfortable visual theme.
- **Local Data Storage** — Keep transaction data in the browser using LocalStorage.
- **Responsive Design** — Use the application on desktop, tablet, and mobile devices.

## 🛠️ Technologies Used

- **HTML5** — Application structure
- **CSS3** — Styling, layouts, themes, and responsive design
- **JavaScript (Vanilla JS)** — Application logic and interactivity
- **Browser LocalStorage** — Saving transaction and preference data
- **HTML Canvas** — Drawing financial charts

## 🚀 Getting Started

### 1. Download or Clone the Repository

Clone the repository using Git:

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

Or download the repository as a ZIP file and extract it.

### 2. Open the Project

Open the `SpendWise` folder in Visual Studio Code.

### 3. Run the Application

Open `index.html` in your browser.

For a more convenient development experience, you can use the **Live Server** extension in Visual Studio Code:

1. Open `index.html`.
2. Right-click inside the editor.
3. Select **Open with Live Server**.

No backend server, package installation, or database setup is required.

## 💡 How to Use

1. Open SpendWise in your browser.
2. Review the dashboard to see your financial summary.
3. Add a new income or expense transaction.
4. Choose a category, date, and optional note.
5. Search or filter transactions to review your spending.
6. Set a monthly budget and monitor your progress.
7. Switch the language or theme based on your preference.
8. Export your transaction records as a CSV file when needed.

## 💾 Data Storage & Privacy

SpendWise stores transaction records and selected preferences in the browser's LocalStorage.

- Data is stored locally in the browser used to access the application.
- The application does not require an account or login.
- Data is not automatically synchronized between devices.
- Clearing browser data may remove saved transactions.
- This project does not connect to bank accounts or a cloud database.

**Important:** This is a personal finance tracking tool, not a banking application or a financial advisory service.
